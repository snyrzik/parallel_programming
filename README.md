## 2. Лабораторная №1 — последовательное умножение матриц

### Задание

Разработать программу на C++, которая выполняет умножение двух квадратных матриц.

Программа должна:

- Считывать исходные матрицы из текстовых файлов.
- Вычислять произведение матриц.
- Сохранять результирующую матрицу.
- Измерять время выполнения вычислений.
- Записывать размер задачи и количество арифметических операций.
- Проверять правильность результатов с помощью Python и NumPy.
- Позволять исследовать зависимость времени выполнения от размера матриц.

### Реализация

Программа написана на **C++17**.

Для хранения матриц используется `std::vector<std::vector<double>>`, позволяющий работать как с целыми, так и с дробными числами.

Реализованы следующие функции:

- `ReadMatrix()` — чтение матрицы из файла.
- `operator*()` — последовательное умножение матриц.
- `WriteMatrix()` — запись матрицы в файл.
- `WriteResults()` — создание папки `output` и запись результатов вычислений.

Умножение реализовано тремя вложенными циклами в порядке `i-j-k`:

```cpp
for (std::size_t i = 0; i < rows1; ++i) {
    for (std::size_t j = 0; j < cols2; ++j) {
        for (std::size_t k = 0; k < cols1; ++k) {
            C[i][j] += matrix1[i][k] * matrix2[k][j];
        }
    }
}
```

Каждый элемент результирующей матрицы вычисляется по формуле:

\[
C_{ij}=\sum_{k=0}^{N-1}A_{ik}B_{kj}
\]

Вычислительная сложность стандартного алгоритма умножения квадратных матриц составляет **O(N³)**.

Для измерения времени используется `std::chrono::steady_clock`. Измеряется только операция умножения, без чтения и записи файлов.

## 4. Компиляция и запуск через g++

Программа компилируется с помощью GCC (`g++`) с поддержкой C++17.

Все команды выполняются в терминале PowerShell из папки лабораторной работы.

### Шаг 2. Проверка компилятора

```powershell
g++ --version
```

Для сборки необходимо, чтобы компилятор был установлен и доступен через `PATH`.

### Шаг 3. Компиляция программы

```powershell
g++ -std=c++17 -O2 main.cpp -o program.exe
```

Используемые параметры:

- `-std=c++17` — стандарт C++17.
- `-O2` — оптимизация кода компилятором.
- `-o program.exe` — имя исполняемого файла.

```powershell

```

Генератор создаёт две квадратные матрицы одинакового случайного размера от 2 до 1000.

## 5. Проверка корректности

Для автоматизированной проверки используется Python и библиотека **NumPy**.

Установка необходимых библиотек:

```powershell
py -m pip install numpy matplotlib
```

Запуск проверки:

```powershell
py verify.py
```

Скрипт загружает исходные матрицы и результат программы C++, после чего самостоятельно вычисляет произведение через NumPy:

```python
expected = A @ B
```

Затем сравнивает полученные значения с помощью `np.allclose()`, учитывая допустимую погрешность для типа `double`.

Успешная проверка:

```text
PASS: matrices match
```

При обнаружении расхождений:

```text
FAIL: matrices are different
```
